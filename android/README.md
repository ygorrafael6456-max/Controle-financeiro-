# Aplicativo Android

Este projeto gera um APK de teste (debug) que abre a versão online do Controle Financeiro em uma janela de aplicativo Android. O login e os dados continuam usando o mesmo Supabase. O APK precisa de conexão com a internet para carregar o sistema.

O workflow `Build Android APK` publica o arquivo `app-debug.apk` como artefato de execução do GitHub Actions.
